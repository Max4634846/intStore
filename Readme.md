# Интернет-Магазин

## Описание
Интернет-Магазин — это клиентское приложение, разработанное на языке программирования C# с использованием технологии WPF. Приложение позволяет пользователям удобно просматривать ассортимент товаров, оформлять заказы и управлять товарами в корзине.

## Технологии и Инструменты
- **C# и .NET:** Основной язык программирования и фреймворк для разработки проекта.
- **WPF (Windows Presentation Foundation):** Используется для создания пользовательского интерфейса.
- **Entity Framework:** Используется для взаимодействия с базой данных.
- **Microsoft SQL Server:** Система управления базами данных.

## Функционал
### Пользовательский интерфейс
- **Регистрация и аутентификация:** Поддержка регистрации новых пользователей и аутентификации существующих.
- **Просмотр товаров:** Возможность просматривать список доступных товаров, использовать фильтры и сортировку для удобного поиска.
- **Добавление товаров в корзину:** Пользователи могут добавлять выбранные товары в корзину для последующего оформления заказа.
- **Оформление заказов:** Пользователи могут заполнить данные в личном кабинете, а затем оформить заказ.
- **Управление учетной записью:** Пользователи могут просматривать и редактировать свои личные данные.
- **Просмотр истории заказов:** Доступ к истории заказов с возможностью просмотра деталей каждого заказа.

### Генерация отчетов
- **Отчеты по заказам:** Пользователи могут генерировать отчеты по своим заказам.

## Примеры использования
### Вход в систему
- Откройте приложение и введите свои учетные данные на странице входа.
- После успешного входа вы попадете на главную панель управления, где сможете получить доступ ко всем основным функциям системы.

### Просмотр товаров
- На главной панели управления выберите "Каталог".
- Вы можете использовать фильтры и сортировку для удобного поиска нужных товаров.

### Добавление товаров в корзину
- Выберите товар из каталога и нажмите кнопку "Добавить в корзину".
- Перейдите в корзину, чтобы просмотреть и изменить количество выбранных товаров.

### Оформление заказов
- Перейдите в корзину и нажмите кнопку "Оформить заказ".
- Подтвердите заказ.

### Управление учетной записью
- Перейдите в раздел "Личный кабинет", чтобы просмотреть и редактировать свои личные данные.
- Просмотрите историю своих заказов нажав на кнопку "Оформленные заказы".
